# FinPulse Trading Platform

A responsive modern trading web application with a React + Tailwind frontend and Node.js + Express + MongoDB backend.

## Features

- Splash screen, login/register flow, guest mode, and JWT-ready auth
- Mobile bottom navigation and desktop sticky navigation
- Trading dashboard, stock marketplace, stock detail pages, portfolio history, profile, and admin dashboard
- Responsive fintech UI with glass panels, soft shadows, animated interactions, and light theme
- Backend APIs for auth, stocks, trades, profile, and admin data
- MongoDB schemas for users, stocks, transactions, referrals, and activity logs

## Run Locally

```bash
npm run install:all
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:5000`

Create `backend/.env` from `backend/.env.example` before connecting MongoDB.
